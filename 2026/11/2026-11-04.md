## 学んだこと・気づいたこと

- TypeScript の型指定
  - `boolean` は真偽値、`() => void` は引数と戻り値を持たない関数を表す。
  - `useState<型>()` のようにジェネリクスを使うことで、State に保存するデータの型を指定できる。
  - `?` を付けたプロパティは省略可能になる。

- JavaScript の分割代入
  - `const { error } = result` は、オブジェクトの `error` プロパティを取り出して変数に代入する構文。
  - `const` は変数への再代入を禁止するものであり、値が必ず存在することを意味しない。

- ログイン認証とエラー処理
  - メールアドレスとパスワードを認証処理に渡し、その結果として返されるエラー情報を取得する。
  - エラー情報に含まれる `status` や `code` を条件分岐に使用し、内容に応じたエラーメッセージを返す。
  - 認証失敗として返されるエラーと、例外として発生するエラーは別々に処理する。
  - `try` は通常の処理、`catch` は例外処理、`finally` は成功・失敗にかかわらず実行する後処理に使用する。

- イベント処理
  - `KeyboardEvent` はキーボードイベントの情報を扱う型。
  - `keydown` はキーが押されたときにイベントを発生させ、`e.key` で押されたキーの種類を取得できる。
  - `removeEventListener()` は登録済みのイベントリスナーを削除する。

- 文字列操作とフォーム
  - `trim()` は文字列の先頭と末尾にある空白を取り除く。
  - `form` は入力・送信を行う領域を指し、フォーム全体に関するエラーと個別の入力エラーを分けて管理できる。
  - 送信中の状態を `boolean` で管理し、処理終了後に解除することで、送信ボタンの有効・無効を切り替えられる。
