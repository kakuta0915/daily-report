## 学んだこと・気づいたこと

- **内部接続と個人用アクセストークンの違い**
  - 個人用アクセストークンは自分のアカウントに紐づき、内部接続は特定のワークスペースに紐づく。
  - 内部接続は、対象のデータベースに接続を共有することでアクセス権を付与できる。
- **API と専用ライブラリの関係**
  - API は HTTP リクエストを使って利用できるため、専用ライブラリは必須ではない。
  - `@notionhq/client` のような SDK を使用すると、API へのリクエストを簡単に記述できる。
- **デモデータと API の違い**
  - デモサイトでは、API から取得したデータではなく、あらかじめ用意された代替データを使用する場合がある。
  - 実際のデータを取得するには、API との接続や認証が必要になる。
