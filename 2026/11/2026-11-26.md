## 学んだこと・気づいたこと

- 設計書はディレクトリ内で管理すると、すぐに確認できる他、Notion よりも GitHub 上で見やすく表示される。
- Git のプッシュエラーは、通信方式・認証・ファイルサイズ・設定など、原因を分けて確認することが重要。
- SSH 接続では、`~/.ssh/config` に設定した `Host` の名前を接続先として指定できる。複数の GitHub アカウントを使い分ける場合にも利用できる。
  - 例：`ssh -T git@github.com-private`
- Git のリモート URL は `git remote set-url origin 接続先URL` で変更できる。HTTPS と SSH では接続先の指定方法が異なる。
- プッシュ後はリモートのコミット ID を確認することで、ローカルの変更が実際に反映されたか検証できる。
