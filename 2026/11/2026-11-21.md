## 学んだこと・気づいたこと

- `fetch` の設定には、JavaScript 標準の設定と Next.js 独自の設定がある。
- `RequestInit` は `fetch` の通信設定に使えるプロパティをまとめた型
- `RequestInit` はTypeScriptで用意されている型で、標準の通信設定を表す。
- `{ next?: { revalidate?: number } }`は、 Next.js で用意されている独自のキャッシュ設定。
  - `next`: Next.js の追加設定
  - `revalidate`: キャッシュを再検証する間隔
  - `number`: 数値を指定する
- TypeScript の `&` は複数の型を組み合わせる記号。
