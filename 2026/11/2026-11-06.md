## 学んだこと・気づいたこと

- Server Component はサーバー側で処理を行うコンポーネント、Client Component はブラウザ側で状態管理やイベント処理を行うコンポーネント。Server Component から Client Component を呼び出すことはできるが、Client Component 側からサーバー専用の機能を直接利用することはできない。
- `Suspense` は、子コンポーネントの処理が完了するまで代わりのコンテンツを表示する仕組み。例えば、認証状態を取得している間に仮のヘッダーを表示できる。
- コンポーネントをまとめてエクスポートするファイルは便利だが、サーバー専用のコンポーネントまでクライアント側の依存関係に含めないよう注意が必要。
- CSS の文字サイズは、子要素に別の指定がなければ親要素から継承される。
