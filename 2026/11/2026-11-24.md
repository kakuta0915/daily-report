## 学んだこと・気づいたこと

- **Fine-grained token** は、アクセス権限を細かく制限できる GitHub の認証方式。API によっては追加の権限を付与せずに利用できる。
- GitHub のコントリビューション情報とコミット情報は、別々の API から取得できる。コントリビューション情報の取得にはトークンが不要な場合もある。
- 複数の非同期処理を `Promise.all()` で実行すると、各処理の完了をまとめて待つことができる。
- データ取得処理と画面表示処理を分けることで、取得結果を共通の形式で扱いやすくなる。
- HTTP ステータス `404` は、リクエスト先の URL に該当するリソースが存在しないことを示す。画面本体の取得が `200` であれば、別のリクエストで発生している可能性がある。
- Next.js のプリレンダリングでは、実行時刻によって値が変わる `new Date()` などの処理に注意が必要。`connection()` を使用すると、リクエスト時に処理を実行できる。
- `for (;;)` は、終了条件を指定せずに繰り返すループ
  後続の処理で終了条件を判定する。
- `orders: `-${FIELDS.publishedAt}`,` の `-` は、降順（新しいものから古いものへ）を指している。
- `of` は、配列などの中に入っている要素を 1つずつ取り出すために使う。
- `??` は Null 合体演算子で、左側の値が `null` または `undefined` の場合に、右側の値を使用する
- `if (!published) continue;` の `continue` は、現在の繰り返し処理をそこで終了し、次の繰り返しに進むという意味
