## 気づき・学び

- Better Auth と Turso を組み合わせることで、認証機能とユーザー情報・セッション情報などを保存するデータベースを連携できる。
- データベースの接続先や認証トークンは、ソースコードに直接記述せず、環境変数で管理することで、ローカル環境と本番環境の接続先を切り替えられる。
- `auth.ts` は認証方式やデータベース接続などの設定を定義し、`route.ts` は認証リクエストを受け付ける API の窓口を定義する。それぞれ役割が異なる。
- Next.js の Route Handler では、`GET` や `POST` などの HTTP メソッドを使って API リクエストを処理する。
- TypeScript の `tsconfig.json` にある `paths` は、インポート時のパスの省略方法を定義する。例えば、`@/*` を `./src/*` に対応させることで、`@/lib/auth` のように記述できる。
- コマンドラインツールをインストールしても、実行ファイルの保存場所が環境変数 `PATH` に含まれていなければ、ターミナルからコマンドを直接実行できない。 `~/.zshrc` に PATH を追加することで解決できる。
- GUI での操作がエラーになる場合でも、CLI から同じ操作を実行できる場合がある。今回、Turso のデータベースは CLI から作成できた。
